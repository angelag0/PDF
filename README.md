# PDF 編輯器 (PDF Editor)

在自己電腦上執行的 PDF 編輯器，用瀏覽器操作。後端為 Flask＋PyMuPDF，前端用 Fabric.js 處理圖片擺放。檔案只在本機處理，不會上傳到網路。

---

## 主要功能

1. **打字（所見即所得）**
   - 在頁面上點一下就出現輸入框，**框在哪裡、字就印在哪裡**：輸入框使用與 PDF 相同的字型檔、字級與行高。
   - 點頁面其他位置會自動放入並開始下一段，適合連續填表；拖曳框左側 ⠿ 可移動。
   - 可設定字級（pt）與顏色；支援多行。
   - 只嵌入用到的字（每段約數 KB），匯出檔不會被 16MB 的中文字型撐大。

2. **文字選取、修改與刪除**
   - 點選或框選文字（Ctrl 加選），右側可修改、複製、刪除。
   - 修改後的文字沿用原本的位置、字級與顏色（字型改用思源黑體）。
   - 刪除只拿掉文字本身，不會補白底、不會動到表格線與圖片、不會誤刪上下緊貼的行。

3. **圖片**
   - 選檔、拖放或直接 Ctrl+V 貼上截圖；可拖曳、縮放、旋轉，確認後合併進 PDF。
   - 直接放入原圖：不重新壓縮、邊緣不會多出細框；旋轉接近直角時會自動對齊。
   - 手機照片依拍攝方向自動轉正。

4. **上一步／下一步**
   - 每次修改前保存整份快照；加字、改字、刪字、圖片、刪頁、裁切都能完整還原，不會在頁面留下白塊。

5. **有密碼的 PDF**
   - 開啟時會跳出密碼輸入框（例如銀行電子存摺、對帳單），輸錯可以重試。
   - 匯出 PDF 時可選擇「不要密碼」（例如只把封面給別人）或「保留原本的密碼」。

6. **隱私**：開啟的檔案只放在記憶體裡，不會複製到磁碟上；關閉程式就消失。

7. **多 PDF 合併**：可加入目前編輯中的檔案，拖曳調整順序。

8. **頁面裁切**：以水平切割線把一頁切成多頁，逐段選擇保留或移除。

9. **匯出**：PDF、JPG（ZIP 打包）、Word (.docx)。匯出前會自動收尾還在打的字，並詢問未合併的圖片。

## 啟動

### 最簡單：雙擊 `啟動PDF編輯器.bat`
會自動安裝缺少的套件、啟動程式並打開瀏覽器。關閉那個黑色視窗就結束程式。

### 手動
環境需求：Python 3.9+

```bash
pip install -r requirements.txt
python app.py --open
```

啟動後開啟瀏覽器訪問 **http://localhost:5000**

## 快捷鍵

| 快捷鍵 | 功能 |
|---|---|
| `Ctrl + Z` | 上一步（打字中則為取消這段輸入） |
| `Ctrl + Y` / `Ctrl + Shift + Z` | 下一步 |
| `Ctrl + Enter` | 打字時：完成這段文字 |
| `Ctrl + V` | 貼上截圖到目前頁面 |
| `Ctrl + A` | 選取本頁所有文字 |
| `Ctrl + C` | 複製選取文字 |
| `Delete` | 刪除選取的文字或圖片 |
| `Ctrl + 滾輪` | 頁面縮放 |
| `PageUp / PageDown` | 上/下一頁 |
| `Escape` | 取消目前的輸入或選取 |

在輸入框裡打字時，以上快捷鍵交給輸入框本身處理，不會誤動到 PDF。

## 測試

先啟動程式，再執行：

```bash
python test_api.py
```

會實際檢查上一步是否完整還原、打字位置、檔案大小、刪字範圍、圖片、刪頁、裁切、合併與匯出，任何一項不符會停下並標出項目。

## 專案架構

```
PDF/
├── app.py                  # Flask 主程式與 API 路由
├── pdf_engine.py           # PyMuPDF 核心處理引擎
├── requirements.txt        # 專案依賴庫
├── test_api.py             # 後端回歸測試
├── 啟動PDF編輯器.bat        # 雙擊啟動
├── fonts/                  # 內建中文字型目錄
│   └── NotoSansTC-Regular.otf
├── static/
│   ├── css/
│   │   └── style.css       # 介面樣式
│   └── js/
│       ├── app.js          # 主控制邏輯
│       ├── pdf-viewer.js   # PDF 檢視器
│       ├── text-editor.js  # 文字選取與編輯
│       ├── image-editor.js # 圖片 Fabric 畫布
│       ├── crop-editor.js  # 水平裁切引擎
│       ├── merge-editor.js # 合併排序邏輯
│       ├── undo-manager.js # 上一步/下一步（呼叫後端快照）
│       └── fabric.min.js   # Fabric.js 畫布庫
└── templates/
    └── index.html          # 主介面 HTML
```
